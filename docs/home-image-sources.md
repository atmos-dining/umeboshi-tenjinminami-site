## 参照元

- ごちポテト: `umeboshi-site/images/topics-card-2.jpg` とこのリポジトリの同名ファイルは同一データ。元からある素材を使用。
- トンカツ: [Retty・食堂うめぼし大名店、2019年5月の実食レビュー](https://retty.me/area/PRE40/ARE122/SUB12301/100001422109/39741317/)

  - [肉断面](https://img.retty.me/img_repo/2l/01/20248510.jpg)
  - 天神南店の現行提供写真とは断定しない。系列店の過去写真を形状・盛り付けの参考として使用。
- 店内: [JIMOHACK福岡・食堂うめぼし天神南](https://jimohack.fukuoka.jp/chuou/14302/)
  - [入口側カウンター](https://jimohack.fukuoka.jp/wp-content/uploads/2024/06/IMG20240618152923.jpg)
  - [テーブル側](https://jimohack.fukuoka.jp/wp-content/uploads/2024/06/IMG20240618152933.jpg)
  - 店内の構造を参照し、人物・私物を除き、光と画質を整えた生成画像。実写そのものではない。

参照先の写真はリポジトリへ転載せず、生成した2画像のみ掲載。以前の `menu-card-2.jpg` はエメラルド、`menu-card-3.jpg` は麺料理の画像であり、ごちポテト・トンカツ用として再利用しない。
